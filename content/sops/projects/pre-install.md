# Pre-Install Confirmation & Crew Assignment

| | |
|---|---|
| **Purpose** | Nobody is surprised on install morning — not the customer, not the crew, not the office. |
| **When it applies** | 3 days before install, and again the day before. |
| **Owner** | Project Manager, with Dispatch for the crew. |

## Three days out — the confirmation call {#three-days}

A live call, not a text. Cover, in this order:

1. **Date and start time.** The crew is on site at the start of the window — the same promise as service, `sop.field.start-time`.
2. **Duration.** Whole day, two days, staged — say it plainly.
3. **Payment stage.** The pre-install payment is due now, per `sop.sales.paperwork`: cash/check to 50% of the total, financing to 90% three days out so the equipment is secured. Take it on the call.
4. **What we need from them**: clear path to the equipment, pets secured, parking, an adult on site at start and at walkthrough, and whether the system will be down and for how long.
5. **What we will do**: floor protection, drop cloths, haul-away of the old equipment, and the site left cleaner than we found it.
6. **Who to call** — the Project Manager's own number.

Then send the written recap by text so it exists in two places.

## Crew assignment {#crew}

Dispatch assigns the crew once the confirmation call is complete:

- Lead installer named on the job — one person is accountable for the site.
- Crew size matched to the scope, not to who happens to be free.
- Install crews are assigned **before** the service board is filled for that day; an install already sold outranks an unsold service slot — see `sop.dispatch.priorities`.
- Confirm the crew's exact start time with the lead the night before.

## Day before — the readiness check {#day-before}

The Project Manager confirms all five, and the project does not roll if one is open:

| Check | Clear when |
|---|---|
| Equipment | Staged and physically verified — `sop.projects.procurement` |
| Permit | Filed/issued, or recorded not required — `sop.projects.permits` |
| Payment stage | Received, or owner-approved exception on the job |
| Crew | Named, briefed, start time confirmed |
| Customer | Confirmed, recap text delivered |

## When we have to move an install {#reschedule}

Call the same day we know, offer the next available date and the reason honestly. When **we** cause the move, the pre-install payment stage does not advance and the customer keeps the original pricing. If the home is without heat or cooling, temporary equipment goes out that day.
