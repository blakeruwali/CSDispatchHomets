# The Project Lifecycle — Sold to Comfort Check

| | |
|---|---|
| **Purpose** | Every replacement or install moves through the same seven stages, with one named owner at each, so nothing sits waiting for someone to notice it. |
| **When it applies** | Every sold install: equipment replacement, new system, major project work. Not service calls. |
| **Owner** | The Project Manager owns the project from the moment it is sold until the comfort check is signed. |

## What a "project" is {#definition}

A project is any sold job that leaves the technician's truck and needs to be **ordered, scheduled, permitted, staffed and inspected**. If it can be finished on the diagnostic visit, it is a service call and this book does not apply.

## The seven stages {#stages}

| # | Stage | Owner | Done when |
|---|---|---|---|
| 1 | **Sold** — signed agreement + deposit taken | Selling technician | Agreement signed, deposit collected per `sop.sales.paperwork` |
| 2 | **Handoff** — project opened and verified | Project Manager | Scope, equipment list, address and contact all verified — `sop.projects.handoff` |
| 3 | **Procurement** — equipment and materials secured | Project Manager | Confirmed order with a delivery date — `sop.projects.procurement` |
| 4 | **Permits** — filed where required | Project Manager | Permit filed or explicitly not required, in writing — `sop.projects.permits` |
| 5 | **Pre-install** — customer confirmed, crew assigned, payment staged | Project Manager + Dispatch | Confirmation call complete — `sop.projects.pre-install` |
| 6 | **Install** — the work | Lead installer | Startup readings recorded, site clean, customer walked through — `sop.projects.install-day` |
| 7 | **Comfort check** — the follow-up visit | Project Manager | Comfort check done and documented — `sop.projects.comfort-check` |

A project never skips a stage. It can move fast through one, but it is entered.

## One owner, always {#ownership}

At every moment a project has exactly one name against it. "Sales thought the office had it" is the failure this book exists to prevent. When you hand a stage on, you say so on the job in ServiceTitan — the handoff is written, not verbal.

## The clock {#clock}

| From | To | Standard |
|---|---|---|
| Sold | Handoff verified | Same business day |
| Handoff | Equipment ordered | 1 business day |
| Sold | Install date offered to customer | 2 business days |
| Install complete | Comfort check | 10–14 days |
| Install complete | Warranty registration | 5 business days |

Miss a standard, note why on the job. A missed date that nobody wrote down happens again next week.

## Money follows the stages {#money}

Deposit at signing, the staged payment before install day, balance at completion — the amounts and the timing live in `sop.sales.paperwork` and the payment terms reference. **Equipment is not ordered against an unpaid deposit**, and a crew does not roll on an unmet pre-install payment stage without the owner's approval.
